# P4-01 Windows 待验

本轮所有 Windows 项 NotRun，沿用 P3-06、边界、B/C/D/F/H 的原完整检查。

1. 默认启动 Off；保存不启用、不发送。两官方预设、手输模型、BasePrefix/自定义端点/ExactEndpoint 的预览与实际请求一致；完整地址误放前缀模式明确指引，不猜多个URL。非法URL/用户密码/query/端点路径、参数范围、危险header不能保存/发送。
2. 手动能力五项 Unknown/Supported/Unsupported：改模型/协议/地址自动重置，普通成功文本测试不自动宣称视觉/温度/JSON支持。温度不支持/未知省略并提示；stream不支持请求false且JSON一次显示；token策略准确，Anthropic max_tokens必填。
3. 明确授权本机HTTP或远端HTTP风险设置后，测试/结果持续有非加密提示；TLS不绕证书验证、跨域重定向不转凭据。自定义认证值只加密保存，不回填旧密钥，不进prompt/日志/导出。公开fixture合成凭据可用于本清单；真实密钥/费用需单独授权。
4. 设置中测试已保存配置，未保存字段/新密钥有明确提示。确认窗口只包含固定公开样本、目的地址/模型/费用提示；取消零调用，Off测试保持红色且不UIA/截图/剪贴板。已有生成时测试拒绝，不争抢；两协议分别流式/JSON/错误/取消检查。
5. 测试中改字段/切profile/保存/恢复/关闭设置/Off/锁屏：取消原任务，不接纳迟到文本/完成/异常；实际原任务结算后关闭，不因点击次数建立多个请求。测试与主浮窗事件分别正确显示，历史结果可回看。
6. 正式文字生成中换当前profile/模型/参数，旧生成取消、旧缓存保留；普通重新生成用旧版本快照，“当前设置重翻译”用新参数。其他独立消费者的未撤销绑定不被误取消。
7. 显式本地测试模式仍按原边界清单：远程地址/端口/run/认证/secretRef/自定义头不能扩展命令授权；新endpointPath/HTTP风险开关也不能扩展。正确结果标本地测试，普通HTTP许可本身不构成测试标识。
8. 真实跨应用、焦点、流式动效、多屏DPI/滚动、DPAPI/ACL、原生DLL、安装卸载、P0/E06、正式服务冒烟和模型质量需独立实际证据。Linux编译、策略/真实loopback测试不是这些项目的替代。
