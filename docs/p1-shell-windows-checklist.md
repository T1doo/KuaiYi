# P1 Windows 待执行清单

本文件是待执行步骤，不是通过报告。全部实际 Windows 行为当前 NotRun。审查包是框架依赖 win-x64 文件，需要 Windows 11 x64 和 .NET 10 Desktop Runtime；没有安装器、开发签名、身份包注册或原生 DLL。

正常启动 `app/KuaiYi.App.exe` 应只显示红色浮钮和托盘，默认无请求、无选区/剪贴板读取；设置窗口为显式入口。`--platform-review` 打开旧 P0 OCR/OLE 评审面板，该面板的本次本地许可与正式 API 主开关独立。`--diagnose`、`--ocr-probe` 保持原诊断命令。准备图片命令仍进入本地 P0 确认评审，不是完整产品图片入口。

1. A01/A02：无配置启动、已有合成配置启动均为 Off；缺文字 profile/模型/SecretRef 时引导设置；启用弹窗显示真实配置 origin 和当前模式；拒绝保持红色，接受只变绿，不生成假结果。本包尚无 P3/P4 完整采集/模型 UI，不使用真实凭据或调用模型。
2. A03：按系统阈值与6 DIP两者中较严格值测试100/125/150/200% DPI；拖动不切换，短点击只切换一次，双击两次独立切换；系统撤销鼠标捕获时清理 Moving。非激活与圆形 HWND 之外点击穿透需真实记录。
3. A09：托盘/右键隐藏同时 Off；显示、重复启动、解锁恢复红色，不重放。启用后重复启动且浮钮已经可见时不自动停用。托盘在隐藏时启用须先显示浮钮。Explorer 重启后托盘重建，失败应显露可恢复入口。锁屏时任何迟到 UI/HTTP 回调不能继续。
4. 单实例：同用户同会话重复启动只能有一个正常主实例；另一个 Windows 会话独立。核 SID、会话命名 mutex 和默认 Windows 对象 DACL；同账户恶意进程不是可完全防御的边界。重复 `--prepare-image` 返回3而不转发未认证路径，正式图片 IPC 仍须安装角色校验，不把窗口消息当载荷通道。
5. 位置：拖动后正常退出再启动恢复归一化位置；负原点、不同 DPI、工作区/任务栏变化、移除已保存显示器重新夹紧；隐藏期间拓扑变化不能因 SetWindowPos 自动显露。记住位置关闭时不自动改写 LastPosition。不可容纳48 DIP按钮的工作区应保持Off并保留托盘恢复。
6. 设置：打开暂停被动候选，取消不落盘；保存按原事务通知定向撤销 profile 绑定。退出或锁屏时掩码并等待实际保存任务结束，不能提前 Dispose 草稿或伪称回滚。位置自动保存先等待启动，并与设置打开串行；并发外部配置写入发生CAS冲突时保留原配置。
7. 退出：托盘退出撤销资格、等配置/位置任务实结算、关闭正常设置窗、注销系统事件和托盘、释放本实例 mutex。用真实 Windows 进程/句柄观测确认；Linux子进程互斥不能代替Windows SID/DACL和托盘清理验证。

P0/E06、真实UIA/COM、自然生长、热键、DPAPI/ACL、图片身份与安装卸载仍需各自退出证据；本轮不将106条整体验收中的任何一条改成Pass。
