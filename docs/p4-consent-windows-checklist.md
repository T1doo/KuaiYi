# P4 固定测试授权与预算补验

本轮全部 Windows 项 NotRun；不替代原 P4/P3/边界清单。

1. 首次仅同意固定公开样本测试，成功后主按钮仍红；真实翻译启用应再次出现真实选区/截图上传目的说明。拒绝后不取词/上传。取消、Off、锁屏、epoch变化导致测试未启动或中断，都不能留下普通内容授权。
2. 测试仅授权该次profile binding/identity/origin；已有另一个服务的普通授权不扩大测试目的，正常授权也不因测试取消被撤销。测试身份被替换后旧目标不能再发送。
3. 测试确认打开、等待密钥、等待响应、流式及目的队列积压时分别编辑密码、认证头名、温度、token/限额、超时、模型/URL/端点、能力、headers及全部checkbox（鼠标/键盘都覆盖）：旧测试取消，旧完成不标新配置成功；确认原intent不能发送。关闭等待原任务结算。
4. 60/120/180/600秒总预算按保存快照执行；凭据等待计入同一起点，HTTP不另起120秒。连接/首响应/idle独立截止仍保留，较大总值不等于可绕过30秒无响应阶段。记录单调时间和真实返回，不修改时钟/证书/安全设置。
5. 仍只用公开本地fixture与合成凭据，不能连接真实模型或读取实际账户key。原文/密钥不得入日志。已签收显式测试模式固定回环/无凭据/client兜底不放宽。

框架依赖审查包无安装器/原生DLL；P0/E06、真正跨应用、焦点/动画/多DPI/DPAPI、安装卸载、真实服务和远端CI均待独立验证。
