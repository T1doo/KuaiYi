# P3-06 Windows 真实文字与本地测试服务复核

本轮全部 Windows 用例 NotRun。Linux 编译、受控采集端口和真实 loopback HTTP 不证明 Windows 取词、焦点或动效。沿用 C/H 兼容矩阵与 B/G 几何、性能要求，P0/E06 仍 Blocked。

1. 安装前置 .NET 10 Desktop Runtime 和 ASP.NET Core Runtime（仅测试服务器需要）；本包为框架依赖审查构建，无安装器和原生 DLL。正式 Drop 及其他原生能力必须先在 Windows 按原工程脚本构建，缺 DLL 不是通过。
2. 在独立终端执行 `dotnet test-provider/KuaiYi.MockProvider.dll`，读取它实际打印的 `KUAIYI_MOCK_URL`。用该地址加 `runs/<32 位小写十六进制 GUID>/fragmented/`，启动 `app/KuaiYi.App.exe --translation-test-provider <完整地址>`。默认启动绝不使用 Mock；此命令使用自己的临时配置，无真实密钥，界面持续显示“本地测试输出”。如果已有主程序，先正常退出，单实例不会把测试参数静默转交。
3. 用公开 fixture 内容测试 Chrome、Edge、PDF 阅读器、Markdown 编辑器、WPF/Win32 对照应用。启用前/Off/锁屏/隐藏/设置中：无自动捕获或 HTTP；启用后真实划选、快捷键当前选区和实际 COPY Drop 的 HTTP user 内容必须准确。受保护/密码/终端/权限不够时拒绝，不读全文。
4. 记录焦点 HWND 与前台窗口：自动翻译/首 delta/后续 delta 不激活快译；点击阅读/设置/长文本确认属于用户主动交互。确认不强制把焦点切回来源。来源窗口/PID/进程时间在发送前改变，旧请求必须拒绝。
5. 用服务的 `slow`、`held-headers`、`disconnect`、`unauthorized` 场景及受控 `/barriers/<run>/release`：A→B 只更新 B；Off/隐藏/锁屏/删除或换密钥取消；旧文本/完成/错误不能写 UI。断流和失败不冒充完成，旧成功结果可回看。
6. 原文 Unicode 标量 12000、12001、50000、50001（含代理项）边界：软限额显示实际长度与目的地址，取消零调用；确认后仅一次完整请求；硬上限拒绝、不截断。长文本确认打开后改来源/配置/Off/锁屏，旧确认不能发送。
7. 重复同一来源、文本、风格与语义配置、收起与回看：零新增请求。重新生成：复用所示版本原文和旧配置、不再 UIA；“按当前设置重新翻译”使用新配置。连续四次重新生成，显示最多三版本；失败版本标停止，旧成功版本仍可阅读；连续来源替换失败仍保留最后可读缓存。
8. 四角、四边、极窄工作区、负坐标多屏、100/125/150/200% DPI、跨屏拖动、任务栏变化、减少动画、高对比、阅读滚动与生成中收起，执行 B/G 全部原要求。记录视频、帧时序、工作区/按钮/窗口几何；不得用本轮纯 Frames 测试代替。
9. 关闭主程序等待 Provider 原任务及各捕获子进程结算；断网、错误、退出不产生用户原文/译文/密钥文件或日志。测试服务器仅保存测试 fixture 请求于内存，不应用于私人内容。

远端 CI、Windows DPAPI/ACL、原生 DLL、实际跨应用、DPI/焦点、安装卸载、真实付费模型均未执行。本清单不把任一完整 A—L 验收项改为 Pass。
