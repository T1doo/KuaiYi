独立临时配置、公开本地fixture，不读真实key/真实模型；原P4与超时清单继续适用。

1. 高级四字段鼠标/键盘编辑、越界/非整数/null文件、旧schema缺字段、保存重启/取消，实际UI提示与冻结profile/mapper一致；总预算字段不被阶段覆盖。编辑取消固定连接测试及原待确认意图，关闭仍等原任务结算。

3. SSE首响应/keepalive/未知/空delta/相同usage/半UTF8及半事件停滞，有效正文恢复刷新idle但绝不刷新total，原因标签准确、部分正文保留。关闭/锁屏/切profile/设置改变时，无晚到完成/错误串版或自动重复付费请求。
4. JSON缓慢有效文本/escape/UTF8正常读完后一次展示，空白/未知字段/重复属性/坏escape/大字段仍有界，无有效活动及总上限均终止；HTTP truncated/abort不因JSON看似完整就假成功。记录字段重排对保守识别规则的影响。
5. 普通旧版重新生成用其阶段预算，按当前设置重翻译取新记录；新保存profile阶段变更取消其运行任务，其他共享profile/消费者原合同不扩大；旧快照标签与参数不改。
