【项目定位】
快译是 C#/.NET10 + WPF/Win32 的轻巧原生 Windows 翻译浮窗。平时收起为可拖动的48 DIP启停锚点；支持选区/拖入文字翻译，以及图片/截图等链路。流式译文从锚点旁展开并随内容生长，可复制译文、展开原文、复制原文、选择本次会话版本与翻译风格。模型连接和皮肤在设置中配置。默认未启用，发送经过授权；“仅内存”只描述本地保留，不等于不发送云端。

【这一阶段已做的前端改动】
1. 默认视觉转为浅蓝主色，搭配薄荷、淡紫、浅粉的玻璃风格；亮绿实心按钮换成小玻璃圆珠，48 DIP点击区保留。
2. 加入云朵/流体/泡泡轮廓与逐像素透明窗口，处理灰色矩形底框。当前是自行绘制的玻璃风格，不宣称已经实现真实桌面磨砂模糊。
3. 顶栏精简为风格、复制、更多；生成中保留停止。设置、重译等移入更多；单版本隐藏版本入口；原文展开后才显示复制原文。相关操作采用完整按钮形态。
4. 中文等线搭配Segoe UI Variable英文；公开预览为16 DIP正文、约25 DIP行高、460 DIP窗宽，缩短段间距，示例使用自然段。真实译文和原文的内容结构不擅自改写。
5. 默认设置导航从七项精简为翻译与模型、外观、快捷操作；其他类别、搜索、连接细节与高级参数按需展开。设置截图之后，模型页又进一步折叠协议和认证细节。
6. 增加多皮肤预设与预览，但按钮/锚点等还没有完全统一到皮肤变量，请特别指出一致性缺口。
7. 加入只作用于显示的文字节奏控制，33ms调度，缓和大块跳字；保存、复制和取消不等待打字动画。保留220/180/80ms原动画时序、固定锚点、250/600ms取词预算以及密码/来源/取消清理安全边界。

【我希望你重点建议】
- 外轮廓是否仍像波浪矩形？如何改成连续、自然且不侵占阅读区的有机造型？
- 中文字形是否偏细或僵硬？中英搭配、行长、换行、孤行、段落节奏怎样更舒服？
- 工具栏、原文与状态区怎样更统一，既精简又不隐藏必要操作？
- 如何让第一次配置模型更容易，减少术语、选择和无意义步骤？
- 皮肤如何成为完整视觉系统，而非只更换背景渐变？
- 字符出现与容器生长怎样更连贯，同时避免延迟、文字缩放和锚点漂移？
