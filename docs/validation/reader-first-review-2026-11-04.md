# 外部设计反馈落实：阅读优先

用户提供的完整设计反馈已阅读。采用其信息层级、操作分组和皮肤一致性建议；不直接覆盖此前确定的 Esc 局部退出语义、48 DIP 锚点、220/180/80 ms 动画时序和安全边界。

## 本批修改

- 新阅读工具栏布局：正常阅读显示风格、复制、更多；生成中将复制位置用于停止。设置、重译、收起等由原更多菜单承接。
- 窄窗口优先保留更多入口；两侧均无法容纳时增加一行，不缩小点击区域。
- 仅一个来源版本时隐藏底部版本控件，并回收状态行宽度；多个版本仍可选择。
- 原文折叠时隐藏复制原文，展开后在同一原文操作行显示。
- 动效采样终止判定不再要求“重新生成”按钮可见，因为该命令已移入菜单。仍要求文字可见、无运行请求、几何稳定。
