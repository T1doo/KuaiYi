# Watchdog termination evidence gate: offline correction

Baseline delivered `6090dc078d175d2135a5c91dfe6476623ef27758`, tree `26cf8bcd893022534544182247e7e84e268f471f`. Parent review identified a false-positive route: the old parent accepted expiry followed by cleanup even if worker had naturally exited and no actual Kill was issued. The old source/failed-review history is preserved; there was no Windows runtime Pass to revoke.

The parent now invokes a dedicated shared WatchdogGate at measured elapsed >=600ms. It queries the held worker's liveness, requires the non-noop KillRequiredExact call and its actual KillIssued state, and records NotExpired/KillIssued/NaturalExit/KillNotIssued separately. Termination occurs before any reporting write, so the bounded reporting/settlement window does not defer Kill or extend the request budget. Failures do not retry. Later cleanup, including a late first termination, cannot promote missing watchdog evidence.

The private64-byte closed protocol adds four fixed phases: WatchdogExpired12, WatchdogKillIssued13, WatchdogNaturalExit14, WatchdogKillNotIssued15. Budget-reached phases carry bounded elapsed600 and the same original QPC, sequence1, nonce, actual worker identity and case. The trace requires Parked→Expired→KillIssued→ParentSettled, rejects duplicates/out-of-order evidence and prevents failure→success upgrades. NaturalExit/KillNotIssued are recorded as fixed failure stages and survive a subsequent supervision timeout, rather than being labeled WatchdogSettled. Native protocol layout accepts these finite parent-control phases, but the native authorization branch still accepts only Authorize; no COM/target behavior is added.

Parent success additionally requires actual worker exit, observed nonzero exit and IO/start/exit/stderr settlement. Independent supervisor must receive expiry and actual-issued phases, valid settlement, EOF/natural parent0, actual held-worker exit/nonzero and no rescue. Known natural-zero worker exit fails even if a putative issued flag exists. A successful termination request plus an observed exit is controlled-lifecycle evidence; this does not establish forensic cause of exit or any destructor/internal-cache behavior. Forced termination still does not count as release-call evidence.
