# 句首显露与连续轮廓

用户明确要求继续修句首裁切、半控件、临时滑条，轮廓允许自行选择方框或云朵，保留已有动态节奏。

## 实现

- 正文固定最终排版宽度。两侧尚未进入当前原生窗口时保持透明；横向完整进入后，利用最后16DIP留白的生长进度柔和显露。首行高度不足时不显露。未新增等待定时器或改变220/180/80ms数值，正文不缩放。首字显露相位发生了有意调整。
- 保留完整控件显露规则；正文未就绪时状态、版本和失败提示跟随其可见度，不出现正文被截而底部状态先显露。
- 垂直滚动条保留布局宽度，只在窗口达到该布局最大高度、几何追平且确有内容溢出时显示/接受拖动。代码/表格/原文局部滚动逻辑未删除。
- 云朵主体由13节点固定三次Bezier闭合曲线构造，相邻主体段共用切线。去掉高度96DIP的侧椭圆添加分支，采用不等肩部与平缓侧腹；锚点圆形并集与窗口边界裁剪仍保留，未宣称完整最终路径具有数学上的全局曲率连续性。
- 顶栏分隔缩短、减淡；轮廓选择从细调区提升到外观页主区，保留圆角方框、柔和云朵、流体、气泡。颜色与轮廓独立，不改阅读偏好。
