## 原条目与实际行为

继续原 SPEC §8.3、§13.1、P1-03/P4-01 的普通配置导入子项。设置“常规”新增“校验并导入普通配置”；输入完整当前 schema 的普通备份，先看校验后的合并 JSON，再明确确认进入草稿，最后由原设置保存生效。上一生产导出器生成的实际文件已通过本轮导入兼容测试。

输入只接受本地用户选择文件，最多256KiB、16层；未知长度流最多读取上限加1字节，实际缓冲 finally 清零。拒绝无效 UTF-8、重复及转义重复字段、未知字段、旧/未来 schema、缺少任一根模块、非法类型/字段/模板/快捷键。v1 输出语言精确要求 `zh-CN`。原有四字段显示偏好入口仍只接受原4096字节白名单文档，不接受完整备份。

文件中任何非空 SecretRef、自定义请求头、应用排除/复制授权/端点同意列表、位置/显示器元数据或非空 WriteId 都使整份导入失败，不静默挑选可用部分。导入不访问 SecretStore，不导入密钥、请求头、信任域名、热键注册结果或应用授权。JSON 预览与错误提示不回显本机敏感字段或原始失败输入。

合并保留原本机全部配置档、ID、凭据引用、请求头、授权/排除规则、位置及现有默认配置选择；为导入档重新生成不冲突的 ID，本机没有默认选择时才映射文件默认档。普通翻译/模板、显示、图片偏好、触发方式与热键组合进入草稿。导入档能力全部重置 Unknown；两个 HTTP 风险开关无条件清除，含 HTTP 地址时预览明确要求在原 API 高级设置手动确认，否则原保存校验仍拒绝。合计配置档超过16或包含保留本机字段的实际合并配置超过256KiB时，整次拒绝；可见预览也单独限量。检查用临时 UTF-8 缓冲清零。

## 草稿、取消与保存边界

进入前拒绝未保存的新密钥控件、待写/待删密钥、普通脏草稿、只读/未知 schema、恢复或保存状态。捕获现有表单后，以原保存基线做语义比较，记录草稿 owner/revision；预览模态窗期间父窗不能保存。应用必须是同一预览、原 owner/revision、同一有效保存版本，且读取已真实结束；任何编辑（包括 ABA）、取消、关闭或版本变化使预览失效。仅一次内存赋值合并到草稿；读取或应用不写文件，不启用、不发送、不注册系统启动或热键。

取消立即撤销资格，但原读取及 CancelAsync 保留到实际结算；父子窗关闭等待相同原 task。首次 UI dispatch 前关闭也同步撤回资格，之后不会启动文件 reader。忽略取消的迟到读取不能生成可用预览，原读取及取消回调两错均保全。

确认后取消设置窗口会放弃整次导入。显式保存继续使用未改的 SettingsCoordinator/SettingsStore/SecretStore 和原热键事务：发布前失败原文件不变并回滚预备热键；发布后异常按真实文件识别已提交，不伪报回滚；磁盘并发修改仍由原 CAS 阻止覆盖。测试使用真实临时配置文件和原事务代码，热键 participant/SecretStore protector 明确为测试端口，不是 Windows 注册/DPAPI 验收。没有覆盖用户选择的导入文件或未知目标文件。
