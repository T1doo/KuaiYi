4. 同屏展开态拖动保持可见尺寸，文字继续缓存；整体卡片夹紧工作区。跨125/150/200%DPI时保留同一次捕获手势、原始按下抓取比例、Moved闩锁与资格，重新基准屏幕坐标；松手必须Released并保存，不能变成Click切On。拖到较小屏允许立即缩小以确保A⊆C⊆W，松手后重规划/测量。包含“拖动时首批正文到达”以及动画未完就拖动。
