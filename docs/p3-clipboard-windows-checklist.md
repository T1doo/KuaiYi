# P3-04 复制兼容：Windows 待执行

全部 **NotRun**。仅监督审查构建，需 Windows 11 / .NET 10 Desktop Runtime，不是安装器。仅使用公开测试内容；保持真实模型调用关闭。继续原 P3、输入身份、绝对截止及 P0/E06 清单。本轮未证明任何应用的复制兼容率或格式恢复品质。

1. 默认 Off、无应用授权：普通选区、主动指令、UIA失败均不得发送 Ctrl+C。分别授权一个完整路径、撤销、同名不同目录、并发设置保存/旧设置草稿、通知失败后重启恢复，检查旧 epoch 不再复制。授权对话框默认“否”，必须真实人工确认，便携测试不代表用户授权。
2. 在六核心应用、18个视图的原兼容矩阵使用真实 MTA Broker。正常 UIA 成功不复制；失败只能凭原窗口/PID/启动时间、原生焦点、可信控件/选区和明确授权进入兼容。主动指令允许无鼠标选区；自动必须有真实关联选区，不得伪造矩形。虚拟无原生 HWND/隐藏剪贴板 owner 无法关联时明确拒绝。
3. 密码控件、终端、被排除应用、更高完整性来源、Ctrl/Alt/Shift/Win/C 未释放、窗口/焦点切换、快译自身：零复制。不得强制恢复前台。检查 SendInput 部分成功仅释放已可能按下的键，不重复复制；记录结果而不记录文本。
4. 真 STA、消息泵、私有自有 ClipboardHost：保存完整格式组合后才 Ready。公开样本分别验证 CF_TEXT/OEMTEXT/UNICODETEXT/LOCALE、HTML、RTF、CF_HDROP、PNG及有限 DIB/DIBV5。保存/恢复逐格式校验完整字节、格式顺序与数量；GDI bitmap/metafile/palette、虚拟文件、任意自定义/OLE、过多/过大/延迟渲染改变组合均在 Ctrl+C 前拒绝。系统自动合成的 GDI 格式使整个组合被拒绝属于保守限制。
5. Ready 前/后改剪贴板或来源，350ms 的349/350/351边界，不变化、非文本、非法 Unicode、超大、不匹配 owner/PID/root、新输入、并发用户复制：旧内容不得当新来源。来源判定结合 owner/根窗口/PID/前台/焦点/输入时间，不以 sequence 单独证明来源。
6. 条件恢复在同一 OpenClipboard 锁内复核此次观测的 sequence 与 source owner，未变才完整恢复；任何后续写入不覆盖。提前分配全部恢复块，Empty/SetData/Close 部分失败明确 Unconfirmed。恢复不宣称原 owner、系统历史、云同步或第三方历史被还原/删除；界面应显示限制。
7. Off、锁屏、模式切换、设置暂停/撤销、下一手势、取消分别发生于启动、Ready、复制等待、结果读取和目标队列。原文不进入目的地；取消立即释放排队快照引用，未交付数组清零且唯一观察者处理异常。锁屏/退出清理已接受的内存原文。
8. 阻塞 GetClipboardData/延迟渲染/恢复/stdio：1200ms父绝对交付预算不续期；已发送复制后 EOF 撤销，允许至多400ms独立恢复宽限，然后仅终止持有的自有服务。持有启动/退出结算未完成时不得第二 writer。部分恢复或被终止只能标未确认，不能虚报恢复成功或“精确时刻终止COM”。
9. 公开 GrowthHarness 禁用实际选区平台；正式 App 才连接生产客户端。检查失败提示不激活阅读应用，同类自动提示每应用30s限频，无原文持久化、无模型/上传。Drop 模式无自动鼠标采集；本轮主动读取不是完整文本 OLE Drop。
