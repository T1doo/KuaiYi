# ADR0018 可选自定义风格模板与完整预览

状态：源码实施，Windows/J质量未验；父限定基线222b057。依据SPEC8.2/9.1/9.9及PromptProfile边界。

沿用schema1的可选字段增补：四模式不可变字典、缺字段默认空。旧v1只补内存默认，不自动改文件；旧v0迁移和未来版本只读策略保持。基础约束不是设置字段，风格自定义仅普通字符串，无代码/环境/文件/外部工具渲染器。程序独立门控不依赖模型如何解释用户模板，固定公开测试忽略模板。

五变量单次替换。source_text与“不把原文插入system”的要求通过固定独立user资料引用协调，界面明确说明；完整原文始终user。模板8192、展开28000、完整system32768，上界与UTF16合法性在保存/预览/生产请求统一核验，逐段追加先查剩余空间。单次替换防止把领域/背景中的占位文本递归变成指令；字面系统表达式不执行。

Compose统一预览/请求，提供不可编辑base、风格、可选上下文、regen、完整system与单独user的来源记录。预览仅公开样例/明确查看模式；不声称当前捕获内容已预览或上传。版本以原模板SHA256绑定内容，旧配置/模板在内存版本冻结；普通重生沿旧映射，当前设置动作独立取新保存默认。模板映射结构相等用于去重，不用字典引用相等。

设置命令修改前调用统一DraftEdited取消配置测试；有效已发普通生成保留旧快照，旧待发送配置意图拒绝。这个合同保持此前通用消费者/共享profile规则，不能为模板取消扩大到所有请求。真实WPF事件/DPAPI/模型语义遵从/安装均须独立验证。
