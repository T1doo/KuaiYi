# ADR0017 当前会话风格覆盖与可读版本序号

状态：源码实施，Windows待验。依据SPEC9.9/P4-05与父限定放行322aea6。

会话覆盖是目的线程上的内存枚举，与已保存默认/每版不可变请求快照分开。切风格不取消或重写已发请求，只撤销待确认意图。普通重生成从所示旧快照重建四模板及明确覆盖，按当前设置的动作独立取新保存默认；旧Prompt和Settings对象不变。Begin同步发布用于版本/风格标签，但实际像素先于HTTP仍需Windows测量；菜单在用户发起前显示预览。

regenerate@1仅追加规格事实保真原句，不引入seed/强制temperature，不承诺每次语义或措辞差异。原base+style TemplateVersion留存，独立字段记录附加模板，FullTemplateVersion提供完整来源。正文不进system。

缓存区分所示版本号与会话创建序列；读旧版或换来源失败回退不会回绕序号。保护原rollback/生成/所示版本，按创建号淘汰，含生成版最多三份同来源版本及元数据。跨不同来源失败回退保持已签收合同，最多旧3+新1元数据；不把四份跨来源回退误称同来源三版。每版保留原配置/风格/来源引用，内存-only无历史保存。
