# 密钥命令 Windows 补验（全部 NotRun）

复用原P4配置/授权/预算清单，仅补本次真实控件入口。使用独立临时配置、公开本地fixture和合成凭据，不读正式key、不真实模型。

1. 保存合成密钥后重开设置，确认PasswordBox为空且只显示“已保存引用”；固定测试等待HTTP时点真实“清除密钥”按钮，原任务取消、原成功不显示、租约在任务实际结算后释放。分别鼠标Click与键盘Space/Enter。
2. 用Dispatcher队列屏障扣住旧完成后清除，释放队列不能显示旧成功；待确认公开测试意图在清除后失效。关闭仍等待原实际任务结算。
3. 预设按钮在控件值已经等于预设时仍显式失效再清引用，不依赖 Selection/Text事件；原测试不能显示成功。
4. 清除仅草稿：取消并重开仍有原保存引用；保存后原引用被原事务撤销/密文删除，不能借旧identity再读取。日志不得含凭据。
5. 无选中profile命令不取消其他请求；新输入/显示/遮罩的原行为正常，不回填已保存秘密。

本地托管命令体+测试控件端口不替代真实WPF事件/DPAPI/Windows安装与原生验证。
