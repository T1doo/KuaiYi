# P3 真实 Windows 待执行清单

全部NotRun。该包为框架依赖win-x64审查文件，需要Windows11与.NET10 Desktop Runtime，包含实际CaptureBroker，不是安装器。不得将Linux公开子进程协议测试当作跨应用UIA验收。正常app尚未连接P4模型调度，工具提示明确只读取选区，可显式查看真实原文；不能称文字Alpha。

1. 正常启动红钮/Off：确认没有自动选区hook线程/Broker。Off、隐藏、锁屏、Drop均不得自动读取选区。设置/移动暂停，松手恢复只监听新手势，不回放旧候选。公开浮窗探针已显式禁用真实选区平台。
2. 配置合成或自有配置后在桌面明确启用；本轮不要真实模型调用。Selection模式从真实鼠标拖选、双击、三击获取非空选区；单击工具栏、滚动条或旧保留选区不可触发。快速A再B去抖180ms，仅最后仍稳定的来源可接受。
3. Chrome/Edge网页、PDF文本层（Edge/SumatraPDF/Acrobat）、Markdown编辑器（Obsidian/Typora/VSCode）逐应用记录版本、窗口/进程、选择手势、文本对照、范围与耗时，初始全部NotRun。密码框、终端、管理员/受保护进程、无UIA自绘界面拒绝，不能读取整页或旧剪贴板补偿。
4. Ctrl+Alt+D默认主动读取当前选区；Off不读取，Drop下可主动读取键盘选区。现有已保存translateSelection组合只支持Ctrl/Alt + A-Z子集、冲突保留旧键并给菜单入口；完整快捷键录制/成组事务仍待后续P3。Windows冲突/焦点行为未验证。
5. 窗口销毁、前台切换、PID/控件/选区变化、配置提交/排除新增、关闭或锁屏：目的UI队列最后资格检查拒绝迟到结果。原source/结果缓存不因无效捕获清空，锁屏/退出清原文窗口和内存引用。
6. 软预算250ms，硬截止600ms放弃结果并只终止实际启动者持有的子进程。故意卡死UIA provider时UI仍可操作；启动或退出未结束不能建立第二份Broker。清理未确认时保留所有权/明确失败，不靠随意PID Kill。
7. 同应用60秒内三次崩溃/硬超时后自动捕获暂停30秒；其他应用不受影响，成功捕获清计数。已授权复制兼容路径本轮仍未接入且绝不自动Ctrl+C。
8. 单字母/公式/emoji、段落和代码缩进、不连续范围按提供者逻辑顺序验证。12000标量软上限提示需确认；50000硬上限拒绝、不拆分/截断。生成器/发送工厂尚未接入，本轮网络请求应为零。
9. 检查鼠标hook仅记录按下/抬起，独立消息泵，有界64事件队列溢出会废弃手势，不记录轨迹/键盘内容。确认停止hook、退出和切模式的真实Win32消息时序及多屏DPI阈值。

兼容矩阵证据、UIA稳定关联、hook生命周期、真实焦点/像素/DPI以及P0/E06均未通过。Drop的完整正式OLE文本落点接入、复制兼容授权流程、全产品热键和P4模型调度尚未交付，不以模式互斥取代这些功能。
